| GS-GLES31-CS-DC-001 | The graphics library shall provide the API function`glDispatchCompute` to launch one or more compute work groups and start compute shader execution.                                                | The function launches compute work groups according to the specified X, Y, and Z work-group counts.                                                                        | `void glDispatchCompute(GLuint num_groups_x, GLuint num_groups_y, GLuint num_groups_z);` `num_groups_x`, `num_groups_y`, and `num_groups_z` specify the number of work groups to be launched in the corresponding dimension. | OpenGL ES 3.1 Specification, Section 17                                                    | No         | Req-GL-002   | Test                |
| GS-GLES31-CS-DC-002 | The`glDispatchCompute` function shall use the active compute shader program to execute the dispatched work groups.                                                                                  | A compute dispatch requires an active program containing a valid compute shader executable.                                                                                | The active compute shader determines the executable code and local work-group size used for the dispatch.                                                                                                                            | OpenGL ES 3.1 Specification, Section 17                                                    | No         | Req-GL-002   | Test                |
| GS-GLES31-CS-DC-003 | The`glDispatchCompute` function shall generate `GL_INVALID_OPERATION` when there is no active compute shader program.                                                                             | The error is generated when no active program for the compute shader stage exists.                                                                                         | An active compute shader program is a successfully linked program containing a compute shader executable and selected for compute execution.                                                                                         | OpenGL ES 3.1 Specification, Section 17                                                    | No         | Req-GL-002   | Test                |
